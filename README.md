## Privacy Policy for Jira Integration

This repository contains a bilingual (English + Chinese) privacy policy for Jira app configuration.

- HTML page: `privacy-policy.html`
- Markdown source: `privacy-policy.md`

Use a public HTTPS URL in Jira, for example:

`https://yourdomain.com/privacy-policy`

Recommended: host `privacy-policy.html` at that URL.

### Quick publish options

- GitHub Pages
- Netlify
- Vercel
- Any static hosting with HTTPS

### Before going live

- Replace `privacy@yourdomain.com` with your real support/privacy email.
- Replace `[Insert company registered address]` with your real registered address.
- Review legal wording based on your jurisdiction and data practices.
